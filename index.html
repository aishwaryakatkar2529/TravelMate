Overview

About the Project

🎯 What is TravelMate?

A full-featured travel tour package booking platform where users can browse curated destinations across India, view detailed package info, and register/login to book their dream trip.

☁️ How is it deployed?

The entire application is hosted on an AWS EC2 instance running Ubuntu Server with a complete LAMP stack — Apache handles HTTP, PHP processes logic, and MySQL stores all data.

📦 What does it include?

10 fully detailed tour packages across India with per-person INR pricing, gallery images, inclusions list, and a secure login-protected booking flow.

👥 Who is it for?

Indian travelers looking for curated domestic tours. Designed for groups, couples, families, and solo travellers with packages ranging from ₹8,999 to ₹34,999.

Deployment

How to Deploy on AWS LAMP

1

Launch EC2 Instance

Go to AWS Console → EC2 → Launch Instance → Choose Ubuntu Server LTS → Select t2.micro (Free tier)

2

SSH into your server

ssh -i your-key.pem ubuntu@YOUR_EC2_IP
3

Install LAMP Stack

sudo apt update && sudo apt install apache2 mysql-server php php-mysqli libapache2-mod-php -y
4

Start & Enable Services

sudo systemctl start apache2 && sudo systemctl enable apache2
5

Upload Project Files

sudo cp -r travelmate/ /var/www/html/
6

Set File Permissions

sudo chown -R www-data:www-data /var/www/html/travelmate
7

Import Database

mysql -u root -p < travelmate_db.sql
8

Open in Browser 🎉

http://YOUR_EC2_IP/travelmate/
